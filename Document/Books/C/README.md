# 從零寫出可靠程式：C 語言教科書

本書是 2026 年 11 月 15 日本次編寫的原創繁體中文書稿，不是已出版書籍的翻譯或轉載。面向從未寫過程式、會操作檔案與鍵盤的讀者；只需要基本四則運算。目標是能獨立完成命令列資料處理程式，解釋其記憶體與錯誤處理，並開始閱讀標準文件。

## 版本與使用方式

正文程式採 **ISO C17、hosted（具有標準函式庫）環境**，編譯命令以 GCC／Clang 為例；Windows 入門採 MSYS2 UCRT64。第 14 章另談 C23。C17 與 C11 的主要差別是缺陷修正；C23 的正式標準於 2024 年採用，名稱中的 23 不是出版年份。參見 [GCC 方言選項](https://gcc.gnu.org/onlinedocs/gcc/C-Dialect-Options.html) 與 [WG14 標準工作組](https://open-std.org/jtc1/sc22/wg14/)。

按章閱讀，每章先預測輸出，再手打範例、改一個條件、完成練習，最後才看解答。不要用「看懂答案」代替自己完成。貫穿案例是成績統計工具：先處理固定資料，再抽成函式、管理記憶體，最後讀取檔案。專題使用虛構成績，不涉及真人資料。

## 涵蓋範圍

核心語法、函式、陣列與字串、指標、結構與聯集、手動記憶體管理、分檔建置、文字與二進位 I/O、整數及輸入錯誤、除錯、動態陣列與鏈結串列、排序與複雜度。進階內容包含物件表示、有效型別、別名、`restrict`、原子操作的同步理由，以及閱讀標準與移植 C23 的方法。

## 未涵蓋及限制

這是一本緊湊的循序教材，不是所有函式庫 API 的逐項手冊。網路、GUI、作業系統核心、微控制器驅動、SIMD、完整 Unicode 處理、複數／浮點環境及無鎖演算法證明不在正文範圍；延伸先備見學習地圖。讀完可開始研究專家問題，不代表已成為專家。

本次實際使用 Google 執行中英文搜尋，並以一般網頁搜尋工具補查；後者未揭露引擎。來源查閱日為 2026-11-15。公開 WG14 草案是語意核對材料，**不冒充正式標準全文**；N1570 是 C11 草案，N3096 是 C23 工作草案。Microsoft 文件只採用與本書標準範圍相符的部分，平台擴充不視為 ISO 保證。

本次未在 PATH 及常見安裝位置找到 GCC／Clang／MSVC，沒有安裝編譯器。因此所有 C 程式與安裝、除錯命令均**未在本機實測**；章內輸出是推演結果。程式以小型、可閱讀的完整例子供讀者執行，仍可能有未發現的錯誤。已進行的編輯檢查與內容審閱範圍記於來源檔末尾；未進行真人學習成效驗證。
