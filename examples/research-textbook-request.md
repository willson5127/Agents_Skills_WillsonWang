# 專業教科書編寫示例

以下是委託編寫教科書或工具書的提示範例，不是書稿，也不表示已搜尋或讀過相關文獻。

## 明確指定技能

```text
請使用 $research-textbook。我完全沒有 SQL 基礎，想學 PostgreSQL，
請使用 Google 搜尋官方文件、相關文獻與論壇，寫成繁體中文教科書，
存到 Document/Books/postgresql/。
從關聯資料與環境準備開始，逐步講到查詢、資料建模、交易與並行、
索引與執行計畫、效能診斷、權限、備份復原及進階設計取捨。
請寫出連貫的原理講解、操作範例、練習、解答與學習成果判準。每章都要附實際查閱過的網路來源連結，並解釋來源對應的內容。不要以大綱或測試報告代替教科書。
```

## 自然語言調用

```text
我想從零學攝影，請到 Google 找資料及論壇，
幫我在 Document/Books/photography/ 寫一本分章節的工具書，
一路涵蓋曝光、光學、構圖、色彩管理、後製、作品評估與專業實務，
每章附實際查閱的來源連結、能自己操作的練習及判讀成果的方法，說明本書涵蓋與未涵蓋的範圍。
```

引用書名、作者與網址必須來自實際查閱，不得虛構。未讀到的資料只能標為待查候選，不能宣稱已確認教材品質。
